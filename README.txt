Readme
Project description and features:
A student-based project based on the F1 brand and database. The website contains various pages covering different aspects of F1, including teams, drivers, stats, past and future races, and designs taught in classes. The project includes a working database connection with proper protection against common SQL injection attacks. 
Contains a fully functional account creation and user experience designed with custom settings and themes. The database supports all four CRUD operations.
Each page is designed around a smooth user experience, with safety for different screen sizes included. The future F1 races and stats page is connected live to the official website 
for new and up-and-coming races.
This project is a love letter to F1.

Installation instructions:
1. Using Github, create a Gitclone of the repository and download to your system.
2. Move the project to your web server
- For MAMP or similar platforms, place the project folder in your htdocs directory.
- For other hosting platforms, move it to the appropriate directory.
3. Place, save, run, check your localhost address within a browser and you should be set!

Database setup instructions:
1. Download the SQL dumb from the repository.
2. Create a new database, named f1_db using your preferred MySQL interface or platform.
3. Using a database tool (like phpMyAdmin, MySQL Workbench, or the command line), import the SQL dump to populate the f1_db database with all tables and data.
4. Test for valid outcome and enjoy!
